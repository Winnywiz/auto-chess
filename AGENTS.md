# Kanto Tactics project rules

Read `docs/composition-search.md` before composition work. The full local owner specification is `docs/composition-search-configuration-and-rules.md`; it is excluded from publication because it contains private figures.
The owner's current request takes priority over historical descriptions in that document.

- The owner approved both original and proposed searches, their head-to-head comparison, and a push on 26 October 2026.
- Report the verified comparison and list changes before pushing. The owner authorized the push on 26 October 2026.
- No browser use without explicit permission. Ask before deleting files.
- Keep existing website and extension designs. Preserve a complete local runtime backup before updating them.
- Keep economy numbers private. Do not publish boards copied from Toongcha.
- Use the verified native combat engine, paired seeds and both sides, Seals off and neutral weather.
- Keep the owner's board, item, star, lobby and tier rules in the specification.
- Intermediate anchored forms require their native unlock star. Earlier partial hits use the earlier form.
- Compare legal anchored forms with evolved forms using their native skills and stats, sharing the base evolution family's shop pool.
- Write plainly and briefly. No middle dot or em dash.
